## PWA

Проект поддерживает установку как мобильное приложение (PWA):

- `manifest.webmanifest` — метаданные приложения и иконки.
- `sw.js` — service worker для кеша app shell и офлайн-режима.

### Как запустить локально

PWA не работает из `file://`, нужен локальный HTTP-сервер.

Варианты:

1. VS Code Live Server (рекомендуется).
2. `npx http-server .` в корне проекта.

После запуска откройте приложение по `http://localhost:...`, затем:

1. В DevTools -> Application проверьте `Manifest` и `Service Workers`.
2. На телефоне откройте тот же URL и установите приложение через "Добавить на экран домой".
